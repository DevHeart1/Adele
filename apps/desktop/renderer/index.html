Connect MongoDB Memory

ADELE stores context, conversation history, and long-term memory in a MongoDB database.

MongoDB setup & troubleshooting

Use a free MongoDB Atlas cluster or a local server at mongodb://localhost:27017.

  1. In Atlas: Clusters → Connect → Drivers → copy the connection string.
  2. Replace <db_password> with your database user password.
  3. Add /adele before the ? in the URI (or keep database name adele below).
  4. In Atlas: Network Access → Add IP Address → add your current IP (or allow anywhere for dev).
  5. Click Create Collections after a successful test. The first run can take up to a minute.

If the test times out

Some routers and mobile hotspots cannot resolve mongodb+srv:// URLs. Fix DNS, then test again:

Set-DnsClientServerAddress -InterfaceAlias "WiFi" -ServerAddresses ("8.8.8.8","1.1.1.1")
ipconfig /flushdns
nslookup your-cluster.mongodb.net

Run in PowerShell as Administrator. Replace WiFi with your adapter name if needed (Get-NetAdapter). If DNS still fails, use Atlas Connect and choose a standard mongodb:// URI instead of mongodb+srv://.
