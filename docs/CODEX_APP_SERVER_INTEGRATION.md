# Codex App Server integration

Adele Desktop uses one local `codex app-server` child process over stdio. The renderer talks only to Adele's existing local backend WebSocket; the App Server never receives a public port.

The backend performs `initialize`, `initialized`, `account/read`, `model/list`, `thread/start`, and `turn/start` using the schemas generated by Codex CLI 0.144.2. It selects `gpt-5.6` strictly, accepting `gpt-5.6-sol` only when that is the catalog's available GPT-5.6 variant. Text deltas, completion, usage, reroute, interruption, and failure notifications are handled without retaining raw protocol payloads.

## Regenerate protocol schemas

```powershell
codex app-server generate-json-schema --out apps/desktop/backend/providers/codex_schemas
```

Schemas are generated development artifacts and are ignored by Git. Do not edit them manually.

## Safety boundary

Codex is used for reasoning. Adele remains the sole authority for tool validation, approvals, execution, and verification. Dynamic App Server tools are disabled unless a future integration can route them through those controls.
