Use only sample data created for the demo.

1. Start Adele and show **Connected with ChatGPT** and **GPT-5.6** in the connection panel.
2. Open a sample job listing and a fictional sample resume.
3. Ask: `Review the job listing currently open, compare it with my sample resume, prepare a tailored application, fill the safe fields, and stop before submitting.`
4. Grant screen access when prompted. Show the plan and the execution trace model entry.
5. Approve only the safe, fictional personal-information step. Show the browser fields being filled, then the verification result.
6. Confirm Adele stops before submission and saves only a safe memory summary when approved.
