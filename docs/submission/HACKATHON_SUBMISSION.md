# H0 Hackathon Submission Plan

Target hackathon: H0, Hack the Zero Stack with Vercel v0 and AWS Databases.

## Submission Direction

Submit Adele Web as a full-stack browser/cloud agent:

> Adele Web is a browser-native AI agent with cloud memory, active-tab automation, approval logs, and connected tools, deployed on Vercel and backed by DynamoDB.

## Track

Track 4: Open Innovation.

## Required Stack

```text
Frontend: Vercel / Next.js
Database: DynamoDB
Browser automation: Adele Web Chrome extension
Connectors: Composio/MCP abstraction
```

## Required Submission Assets

- Text description naming DynamoDB as the AWS database.
- Demo video under 3 minutes.
- Published Vercel project link.
- Vercel Team ID.
- Architecture diagram.
- Screenshot proving DynamoDB usage.

## Demo Story

The planned demo should show Adele Web reading a job listing, saving structured memory to DynamoDB, filling safe fields in a browser form, drafting an application response, and stopping before final submission for user approval.
